# О приложении

**MoneyPlanner** - приложение для ведения доходов и расходов с возможностью планирования и формирования бюджета.

# Технологический стек

* Python 3.12
* FastAPI
* PostgreSQL
* Redis
* ClickHouse

# План развития
## MVP

Список функций для первичного запуска:
- [] Возможность зарегистрироваться (пока что без гугла), сбросить пароль
- [] При регистрации создаётся базовый набор счетов, категорий
- [] Пользователь может создать свои счета, категории
- [] Пользователь может создавать транзакции:
  - [] Списывать деньги в категории;
  - [] Переводить между счетами;
